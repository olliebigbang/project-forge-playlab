## 通用规则修正

1. **独立的持枪方式。** 增加`two_hand_free`，让无枪托和双手持握能够共存。
   Python语义/出图校验、Godot轴编译、视觉描述、骨架支撑与握法解释同步接入。
   仍拒绝“无托却抵肩”、弹匣位置冲突等声明；无任何MP5K名字分支。
2. **不要把一根绳声明两次。** 语义提示明确区分主柔软路径、额外独立路径、末端部件。
   复测AI确实去掉重复挂绳声明；因出图失败，没有宣称整条修正链通过。
3. **末端部件保持刚性。** 用Alpha的粗块与细颈分离决定末端绑定区域，
   代替以StrikePoint为中心的固定小方框。只改绑定，不改源PNG、Alpha或声明。
   实际场景对本项目旧自动rig作内存内升级；手工rig与磁盘旧存档不改。
4. **握本体不等于物品短小。** 去掉原包动作层对所有body_grip的紧凑尺寸上限；
   仅真正宽短的轮廓保持紧凑限制。长细轮廓保留长度轴与真实双手距离约束。
5. **原生功能提示补强。** 明确普通接触攻击不应吞掉真实泵/储液/出口的功能声明。
   这只是提示修正，尚无修正后在线复测，不能当成喷水壶漏能力已解决。

新增匿名形状测试覆盖整块高末端不拉伸、Alpha不变、原包层长杆比例和无托双手；
隔离目录注入保留生产默认值。主入口仍是`Play-Sunny.cmd`，未切回教堂。

## 专名物品补测：刀剑类别先归一（2026-09-01）

本轮增加的是通用“专名 → 普通实物类别 → 机制轴”路径，不是两把武器的名字表。AI类别卡
只允许返回短的普通类别和证据；当名称末尾明写了非泛化实物中心词时，字面后缀可作为独立
证据，但“物、器、具、件、品、体、类、装、械、机”等单字泛词不能借此越过置信门槛。
归一后的机制卡必须重新独立评分，不能照抄专名阶段的低置信度。

最终`雪饮狂刀`真实语义卡成功：名称保持不变，类别结构为弯刃单刃刀，置信度`0.85`；
短柄、短主体、单手、刚性、前重、主接触刃、副接触尖，其他软体/状态/输出轴均为无或被动。
证据在`.tools/sunny-live-acceptance/6bfde49f22c74825a43778bb551de381/`。FAL随后在第一阶段身份图
