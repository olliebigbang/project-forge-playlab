# 枪械机制轴 V4

V4 在单发、三连发和全自动之外加入 `manual_cycle`，用于弹匣供弹、每发之间必须操作枪机的栓动步枪。

- 玩家仍然只按普通攻击键，不需要选择攻击方式，也不需要额外按键拉栓。
- 每次射击后，游戏按枪械机制自动完成一次机械循环。
- 循环尚未完成时，按住攻击或快速重复点击都不能提前发射下一发。
- 循环结束后，必须再次按下攻击键才会发射；它不会变成慢速全自动。

机制编译结果使用 `forge-ranged-runtime-profile-v4`。`fire_control` 独占四类最终参数：

- `automatic_fire`：是否按住连续射击。
- `burst_size`：一次按键固定发射的弹数。
- `manual_cycle_required`：是否必须在每发后完成机械循环。
- `manual_cycle_overhead_seconds`：手动枪机在基础击发间隔之外增加的机械动作时间；当前 `manual_cycle` 为 0.54 秒，其余击发方式为 0。

实际的逐发锁定时间为 `shot_interval_seconds + manual_cycle_overhead_seconds`。因此 M24A2 的 `deliberate` 基础间隔 0.28 秒加 0.54 秒机械动作，总计仍为 0.82 秒；同一手动枪机声明改成 `balanced` 或 `rapid` 时，总等待也会跟着 cadence 改变，不会被一个更长的固定锁覆盖。

声明式验收身份为 M24A2。它使用已有的常规步枪、固定枪托、握把前直弹匣、长枪管和上方导轨结构轴；运行层只读取 `manual_cycle` 的编译参数，不包含任何 M24A2 名称判断。AI 协议也允许陌生的、结构可被现有像素轴诚实表达的弹匣供弹栓动步枪声明同一机制。

训练区和 AI 敌人试玩会直接说明“每发后自动拉栓”和总动作时间。射击期间还有一个由同一计时器驱动的轻微枪身循环动作。有限差分审计维持单一所有权：`fire_control` 只拥有机械动作开销，`cadence` 只拥有基础击发间隔；真实运行时将两者相加。
