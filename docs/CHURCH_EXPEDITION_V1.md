# 教堂远征 V1：统一试玩与验收

日期：2026-08-31。主入口 `scenes/church_expedition.tscn`。
这是一段本地可重复游玩的远征原型，不是完整商业游戏。

## 玩家拿到什么

`Play-Church.cmd` 或 `scripts/run_church_ai_forge.ps1` 启动同一入口。
`-Offline` 不读 `.env`，可以用已有武器游玩；正常启动也不会自动请求 AI。
只有在造物页点“生成”才调用原有语义/FAL管线，可能收费。

流程：武器库／文字造物 → 开始并保存 → 第一章 → 营地 → 第二章 →
营地 → 第三章 → 结算 → 换结构或新路线再来。失败保留已完成的章节，
从本章起点重试；Esc 可暂停，返回营地不保存战斗瞬间。

- 每章两处阵眼，每处需累计85秒有效防守；只有玩家在外圈且敌人不在内圈时充能。离开只暂停，不回退。
- 充能判定与地面椭圆使用同一投影，不用隐藏的大圆圈。每完成一处恢复10生命。
- 阵眼完成后击败守门者及余敌才结束本章；清空暂时出现的敌人不算提前通关。
- 增援有1.8秒预告，间隔依次12／11／10秒；同时敌人上限3／4／4，出招协调预算1／2／2。
- Q 消耗一份补给恢复35生命，每章最多带2份。营地全回复并补满2份；并未降低敌人单招伤害以强行制造胜利。
- 第一章理解预告，第二章面对更紧密的交错攻击，第三章加入真实重型攻击蓝图。主场景、美术和输入统一，但并非三个独立绘制的新地图。
- 新路线目前是4种阵眼／入口排列，不是无限地牢。结算保存最近10次记录，并显示实际击退、缠住、钉住、斩切、压制等作用计数。

键位：WASD/方向键移动；J/Space攻击；K/Shift闪避；Q补给；Esc暂停。
枪械HUD显示弹匣/装填/复位，近战显示起手/出招/收招。武器招式仍由已有
轴、接触与状态结构编译，不按园艺叉、壶、链条或枪名写关卡专属招式。

## 武器与美术来源

使用用户提供的 GothicVania Church 同系列环境、玩家、术士和焚行者。
新HUD使用同系紫灰／暖金色，nearest像素，整数预览放大；增援是敌人
实际剪影和倒数，阵眼锚定素材烛柱。最终守门者沿用同系列焚行者外形，
动作依照重型蓝图，没有新画一套独立Boss角色。音频为少量本地合成提示音，
没有完整配乐或正式音效资产集。

随游戏提供5件**既有AI成品**：M4A1、左轮、咖啡壶、园艺叉、挂锁铁链。
三个普通物品来自上一轮真实在线生成；两把枪来自既有校验缓存，经本地
Church调色重新打包。来源见 `assets/church_expedition_starters/PROVENANCE.md`。
此次远征开发没有调用新的付费AI，也不会把这些成品当成新输入的生成结果。

个人完整武器库及兼容的旧枪可读取。调色为独立图片副本、保留Alpha与锚点，
不回写源缓存；开始远征时显式保存新完整包。异常旧条目跳过并提示，原文件保留。

## 可靠性改动

- 独立版本化章节快照，写入后校验；损坏新快照可回退到之前有效文件，不删旧存档。
- 存档失败不发布虚假的内存检查点；重新打开首页不自动用首页默认武器覆盖旧进度。
- 造物失败保持失败，不能悄悄装备样品。旧工坊、草图、后台奖励均保留，但不冒充已迁入新远征。
- 子弹检测扫过实际移动线段，避免高速度穿过目标；Church敌人使用贴合站立／低姿身体的胶囊形受击代理，修复枪口高度与旧根节点小圆不匹配的边界漏判。子弹速度、后坐、散布和伤害轴未因此改写；这不是逐像素敌人碰撞。

## 不能据此宣称

5件通关不能证明所有物品成功、轴完全正交、全武器平衡或已经“值得反复玩”。
首轮约10～15分钟是基于战斗时长加正常阅读/换装的设计目标，仍需用户
实际体验验证。配乐、独立Boss形象、更多地图、长线成长、多人/在线服务、
一句话改造旧武器还没有在本远征闭环；这次没有购买、提交或推送。
