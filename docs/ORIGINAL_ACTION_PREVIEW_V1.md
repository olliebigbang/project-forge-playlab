# 原包全动作训练场 V1

日期：2026-08-31。范围：用户提供的 Dead Revolver 原包动作接入、状态联动、
蹲射低靶验证。不是新的 AI 物品解析器，不是三章关卡迁移，也不是最终人物换皮。

## 打开与操作

双击仓库根目录 `Preview-Original-Actions.cmd`。所有资源离线使用，不读`.env`，
不产生AI费用，不写个人武器库或章节存档。旧剑招、Sunny V2.1和教堂入口保留。

| 操作 | 实际效果 |
| --- | --- |
| 1～5 / 底部按钮 | 剑、原包占位枪、弓、钓竿、徒手；开发训练场选装备，不是让玩家填写AI机制 |
| WASD，Shift，Ctrl | 场地移动，跑步，冲刺；动作同步换为原始走/跑/冲刺帧 |
| J / 空格 | 当前装备攻击；枪可按住连射，弹空自动换弹；弓/竿按住蓄力、松开释放 |
| L | 剑四段连击、枪双手射击、徒手三段踢击 |
| O / B | 剑快斩 / 切换原包两套持剑跑姿 |
| C / G | 手动蹲下 / 切换枪的低靶自动蹲姿；无暗中斜弹道补偿 |
| K / Z / X | 原包翻滚 / 分段闪身 / 滑步 |
| V / H / U | 格挡 / 模拟受击 / 模拟震击眩晕；H、U是测试刺激，不是敌人AI |
| R | 枪械换弹；倒地后通过1～5重新选装备恢复训练角色 |
| P，左右箭头，T | 暂停、暂停逐帧、四分之一慢放 |
| 检查菜单 | 播放全部已载入动作和配套素材；明确标记单项演示，不产生伤害 |
| F / F8 / Esc | 转向 / 保存实际游戏画面 / 退出 |

钓竿：准备→蓄力→松键抛竿→持竿待机→再次按J收线→拉扯→提竿→待机。
保留原作者画出的竿和全身动作，没有额外画调试线当鱼线，也没有鱼、上钩判定或
实际钓鱼小游戏。原包没有持竿走路与持枪蹲走帧：钓竿模式原地操作，持械蹲姿
不滑行；徒手才使用 Crawl。检查菜单中的空中招式不等于关卡加入了跳跃系统。

## 接入方法与边界

- 直接绘制原包完整PNG，不用IK小棍拼接手臂。原白人偶、占位黑枪、原剑绿斩光保留。
- 96×84普通画布用固定脚点(48,84)；143×104钓竿画布用固定脚点(68,104)。
  同一帧内身体/手/武器一起镜像；不逐帧根据透明边界重新居中。
- 原始每帧时间来自相应Aseprite tag；没有统一成任意12FPS。只解析有界元数据，
  不执行包内Export.sh或Aseprite脚本。源PNG逐文件与用户ZIP一致。
- `Effects`原文件有两个同名RunDustFront标签；现解析保留最后一个，即源帧41～48。
  此素材只在检查菜单播放，未作跑步事件。未独立证明同名导出PNG对应哪一段源时间帧。
  `IdleTransition`两张导出PNG没有对应源tag，已复制但不编造时长，不进入运行库。
- `CrouchDustBack`最后3张原PNG为空帧，按原时序保留。图形检查记录其零不透明像素，
  不将空白帧冒充可见动作效果。
- 枪口逐帧来自原包独立Weapon层的真实不透明边界；子弹由该点水平出发、直线匀速。
  实际弹丸和低靶的Alpha做扫掠接触，没有用大隐藏胶囊包住蛤蟆。
- 原GunFire与GunCrouchFire起手枪口相差7个源像素，4倍显示下降28像素。
  自动蹲姿仅在站射无法接触、蹲射能接触且原地时使用。移动中保留走射/跑射；
  不能保证任何矮敌人或不同地面排都靠下蹲解决。
- 剑的实际绿色剑/斩光像素接触低靶时记命中，每段最多记一次。弓释放原Arrow。
  徒手、受击等其余条目主要验证动作/状态，并未替代通用机制轴的代价、伤害与平衡。
- 低靶是不会反击的固定训练图，命中计数不是完整敌人战斗或过关系统。

## 发现后修订的问题和保留限制

- 蹲射收招曾瞬间回GunAim：改为当前姿态的待机，并对收招中松开移动/蹲键回归。
- 初轮钓竿边界只拍Idle且第二循环仍在检查模式，证据不充分；镜像画布的左边界也有
  最长Cast02截竿风险。已改为实际输入链到Cast02和Catch04，覆盖双向、左右边界和
  顶栏，独立复核关闭对应问题。历史失败/不足证据没有删除。
- 极端姿势距屏边/顶栏仍约4～5px，完整但留白较窄。
- 原Prepare03、Cast01自身有较大紫棕色拖影块。忠实导入并不代表其美术质量满足最终
  干净像素要求；此轮不擅自改源图或把它描述成新制作的成品竿动画。
- 白色原型人物、占位枪仍是动画底板。新冒险者皮肤、既有AI武器与这些全身帧的握点
  适配，以及迁移到教堂三章，均未完成；不能把独立训练场当作全游戏升级完成。

本轮没有在线生成、读取密钥、修改个人库/存档、提交、推送或合并其他仓库。
