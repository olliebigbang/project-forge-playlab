# 晴日远行：局外工坊成长 V1

日期：2026-09-03。此版本把“通关后再来一局”的最小成长闭环接入Sunny主流程，
但不保存永久伤害、生命、射速、后坐力或敌人数值。局外成长只扩大以后每局能遇到的
机制选择，并且有明确上限。

## 玩家循环

1. 玩家仍然先描述任意受支持的手持物品，或从武器库选择已有成品。
2. 一局内击败怪物回收锻材、精英核心，在前三个路标形成三项局内构筑。
3. 完成整条长关卡后获得1点通关见闻；若本局武器属于此前未掌握的机制家族，另获1点。
4. 见闻解锁下一局的候选重铸与进阶模块池。原武器包和AI声明完全不改写。

失败不发见闻，打开营地也不写存档。见闻与武器库存放在同一隔离根目录下的不同字段；
快照仍为追加写入，损坏的新快照会被跳过。

## 机制家族

家族只读取已经校验的匿名结构轴，不读取显示名或物品身份：

| 家族 | 结构证据 |
| --- | --- |
| 投射循环 | `weapon_domain = handheld_firearm` |
| 柔性控制 | `flex_topology`或`tether_topology`不是`none` |
| 功能输出 | 可变`state_topology`或非接触型`functional_output` |
| 尖端杠杆 | 固定结构的`contact_surface = point` |
| 刃边接触 | 固定结构的`contact_surface = edge` |
| 宽面冲击 | 其余`broad / whole_body`接触 |

这不是按每把AKM、叉子或水壶分别刷等级。同结构的新物品仍能共享玩家已经打开的选择
空间，但不会自动继承伤害加成。

## 封顶解锁

| 累计见闻 | 解锁 | 对战斗的影响 |
| ---: | --- | --- |
| 1 | 路标重铸 I | 每局可免费替换一次当前三张候选；不返还或消耗锻材/核心 |
| 4 | 进阶模块池 | 每个选择列加入一张更强、代价也更明显的候选 |
| 7 | 路标重铸 II | 每局重铸上限提高到两次 |

进阶模块仍按枪械/普通物品分池，并继续通过现有运行通道改变装填、踏步、起手、收招、
攻击窗口、后坐力、伤害或控制。它们不是只有“进阶”标签的文本卡。重铸使用独立候选
修订号，不改变地图种子、敌人编队、材料或核心，也不会让同一组三张原样返回。

## 界面与验证

- 营地页标题旁固定显示见闻和已掌握家族数量；悬停说明必须完整通关才结算及下一里程碑。
- 出发页说明本局重铸次数与进阶池状态。
- 路标选择页用`R`或可见按钮重铸；进阶卡和核心灌注分别标记。
- 结算页显示本局重铸、见闻、是否新掌握家族、新解锁和下一里程碑。
