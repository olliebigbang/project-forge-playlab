## 做到哪里

独立教堂试炼：同系列背景、玩家、术士和焚行者；可前后移动、攻击、
闪避、清敌获胜、受伤失败、重开和切换武器。没有替换主工坊和三战入口。
这是可操作的美术/战斗样板，不是已发行成品或完整三战换装。

五件可用的本地样品：92 式手枪、81 杠、短柄铁锤、可开合雨伞，以及
明确标注为开发样品的像素鱼竿。前四件来自已验收本地缓存；不是本轮
实时 AI 生成。仍调用生产武器机制和真实像素/握点，不通过名称指定攻击。

## 运行

在仓库目录执行：

```powershell
.\scripts\run_art_vertical_slice_v1.ps1
```

也可从任意 PowerShell 位置执行绝对路径：

```powershell
& '<USERPROFILE>\Documents\ChatGPT\playlab\combat-mechanism-integration-v1\scripts\run_art_vertical_slice_v1.ps1'
```

WASD/方向键移动；Space/J 攻击，支持的结构可长按；Shift/K 闪避；
1–5 或 N 换武器并重开；R 重开；Esc 退出。仅攻击/闪避提供鼠标按钮，
不是已经完成移动触屏适配。窗口默认 1280×720，界面保持比例。

`-Probe` 只检查本地条目；`-Replay` 为机器人输入+真实 Godot 渲染并保存
独立证据目录；`-Smoke` 在无机器人输入的普通模式截取首帧并退出。
这些模式均不读 `.env`、不请求在线生成、不保存装备/奖励。

## 独立视觉复核

审核代理：`pixel_art_aesthetic_audit`（Volta），不是外聘画师认证。

首轮真实截图判为 NEEDS_WORK：地面被读成正面砖墙；另指出术士/预警
对比偏弱、禁用按钮透明。手枪比例与裸臂连接在所看采样中没有阻断。
据此改为后排压缩/接缝汇聚的透视石板，提高地面与警示对比，补不透明
禁用按钮底。v2 原尺寸静帧的地面空间读法已经独立复核通过。

最终 v2 回放原尺寸抽审 11 帧，结论 **PASS（同屏样板，无视觉阻断项）**：
地面空间、紫袍与预警对比、按钮/HUD、92 与 81 杠比例/手臂、伞真实展开均
通过对应采样。仍有地板较素、贴身时局部肢体重叠、枪械/文字像素较细的
非阻断问题。不扩大为连续动画、全部武器平衡、人工试玩或发行认证。
