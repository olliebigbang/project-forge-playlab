# 原包剑招还原小样 V1

日期：2026-08-31。基线`39205a92`，保留已有工作区全部改动。本轮只做用户确认的“原包剑招还原”，不将其称为通用武器机制或正式关卡完成。

## 入口与范围

双击根目录`Preview-Original-Sword.cmd`；独立场景`scenes/original_sword_preview.tscn`。窗口为“Forge — 原包剑招还原（独立离线小样）”。启动即自动演示三种动作，完整播放后换方向；按移动/攻击可接管。

- A/D移动，按住Shift跑步；J/空格全身挥剑，K四段连击，L站立快斩。
- Q开关自动演示，T切换原速/四分之一慢放，P暂停；暂停后左右箭头逐帧，F转向。
- R重置，F8保存引擎截图，Esc退出；底部亦有鼠标按钮。
- 动作中不允许另一攻击或移动强行截断原帧；暂停时可重新触发一套动作。没有额外根位移冲刺，只保留源画布中的发力/脚步位置；非攻击时平移速度是小样设定，不是作者给出的游戏移动速度。

原白色人偶、绿色剑/斩光均为此次正确还原目标，不是新外观制作失败。背景复用既有Sunny宽地面参考图；没有生成新图。小样不生成AI物品，不接个人武器库、伤害、敌人、存档、通用机制轴或教堂主入口。
