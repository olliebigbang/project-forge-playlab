# V1 Scope

Status legend: `CONFIRMED`, `ASSUMPTION`, `TO VALIDATE`, `TBD`.

## Product hypothesis

- `TO VALIDATE`: A player who cannot draw can still express a satisfying weapon fantasy through a sentence, a rough sketch, or both.
- `TO VALIDATE`: A deterministic local compiler can turn that intent into a recognizable pixel weapon with coherent behavior, signature effect, drawback, and anchors.
- `TO VALIDATE`: One natural-language modification after real combat is enough to make room two feel materially different.

## Included

- `CONFIRMED`: Chinese Forge UI with description-only, sketch-plus-description, and sketch-only modes.
- `CONFIRMED`: One optional clarification, never a follow-up chain.
- `CONFIRMED`: 512×512 logical sketch data, mouse/touch drawing, clear, one-step undo, transparent PNG bytes, raw strokes in session memory, and geometry summary.
- `CONFIRMED`: Strict `WeaponBlueprint` data and exactly three behavior families.
- `CONFIRMED`: Replaceable interpreter/image interfaces with offline Mock implementations.
- `CONFIRMED`: Procedural 96×96 pixel weapons, alpha analysis, five anchors, debug view, and JSON overrides.
- `CONFIRMED`: Training, room one, one intermission decision, modified/recast room two, and survey.
- `CONFIRMED`: Keyboard, mouse, and basic touch controls.
- `CONFIRMED`: Local JSONL events with raw text/sketch exclusion.
- `CONFIRMED`: Godot Web export preset and local serving scripts.

## Excluded

Accounts, clouds, payments, store systems, narrative, bosses, content breadth, inventories, progression, unlimited conversations, production deployment, model selection, paid inference, production art, a fourth behavior family, universal IK, and mobile release acceptance are excluded.

## Stop condition

Development stops at a playable V1 suitable for moderated human validation. Findings should inform a separate product decision; they should not silently expand this repository into V2 or be merged directly into a formal product repository.
