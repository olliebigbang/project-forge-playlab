# Moderated Playtest Script

## Setup

1. Run `./scripts/test.ps1` and `./scripts/run_game.ps1`.
2. Start a fresh session and confirm the `LOCAL MOCK` badge is visible.
3. Do not teach internal behavior families or enemy names.
4. Tell the participant that drawing quality is not judged.

## Session A: description only

Ask the participant to select `只描述` and enter: `一把冒蓝火的重型加特林。`

Observe whether the result reads as multi-barrel, is held at the rear/two hands, spins before firing, emits blue projectiles from its muzzle, burns, overheats, stops briefly, and slows movement.

## Session B: rough sketch plus description

Ask for a deliberately rough umbrella outline plus: `会飞出去再返回的机械闪电伞。`

Observe silhouette, shaft grip, spin center, outbound/return hits, electric chain, and attack lock before return.

## Session C: intentionally poor drawing

Ask for a rough long shape plus: `一把会吸血的链锯大剑。`

Never ask the participant to redraw more beautifully. Observe retained long silhouette, teeth, two-hand hold, slow startup, heavy melee, and lifesteal.

## Session D: unclear sketch only

Ask for an ambiguous sketch with no text. Confirm exactly one clarification appears, no second question follows, uncertainty is not disguised, and the result remains one of the supported weapon families.

## End-to-end tasks

1. Confirm the weapon and spend 10–20 seconds in training.
2. Ask where attacks appear to originate and what the drawback is.
3. Complete room one.
4. Use one sentence to modify the weapon, or fully recast.
5. Complete room two and submit the survey.

Record confusion, accidental inputs, completion times, damage, overheats, dodges, whether the modification was perceived, and whether the player asks for unsupported behavior.
