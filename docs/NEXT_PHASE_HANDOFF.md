## 2. 审核结论

值得保留的核心不是枪库，也不是大量剧情文字，而是：
**玩家记得/描述一个物品 → 物品结构决定打法 → 关卡让不同结构有用 → 本局构筑改变行为 → 玩家愿意改造或再试一个物品。**

做得好的部分：

- 自由身份与受控强度分离：强大的名字不直接换来无限伤害。
- AI 放在造物阶段，本地校验和执行；战斗可离线，不执行生成代码。
- 原包动作、真实武器贴图、枪械后坐/低位射击和软体接触已有实装，已有测试基础。
- 横向推进、三选一、短试铸、存档与正式章节已连通；不是只有一张静态展示图。

目前最大问题是“各系统存在”尚未形成足够鲜明的选择：
重复清场/守点偏向高持续伤害；许多强化改变数字但不明显改变操作；叙事文本不能替代目标变化。
因此先完成可测的基础，再扩大内容，不靠增加怪物血量、阅读量或生成等待凑时长。

## 4. 下一任务的具体范围：阶段 1 基础收口

### A. 修复 HUD 重复

- 生命、路标、计时、锻材、核心由状态生成，不从上一次显示文本继续拼接。
- 相同状态刷新 300 次仍只出现一次各资源；拾取、花费、暂停/恢复、章节切换均显示正确。

### B. 验证并修复完整按钮链

- 从真实主入口进入：营地 → 第一章 → 三种路线各一遍 → 简报 → 出发 → 暂停/恢复 → 强化 → 结算 → 回营。
- 鼠标按下/抬起和键盘焦点确认都检查，不用直接调用回调替代交互证据。
- 单次输入只发生一次状态转换；弹窗不被旧连接、遮挡或错误 mouse_filter 截获。
- 自动化断言与真实窗口操作分开记录；缺桌面操作权限时明确留待验证，不能宣称已试玩。

## 5. 后续顺序与验收（尚未实现）

1. **差异化遭遇与小型事件**：在一条横向路线里加入突破、护送/保护、精英战等不同目标；不用换名字重复同一种清场。至少三种目标能让两类以上结构以不同办法完成，无强制物品名钥匙。
2. **行为构筑 + 基本打击反馈**：先覆盖近战、枪械、软体/控制三类，每类两条可辨认路径。选择后 30 秒内能从实际战斗看出行为变化，有代价与叠加边界；命中/挥空/破防的音画反馈可区分，保持有敌人时稳定帧耗。
3. **一句话改造原物**：保留原物身份和历史，用一条描述修改结构；成功改变打法且显示代价，失败明确说明并保留原武器。不暗换成无关缓存。先离线确定性回归，付费在线验证另按授权范围。
4. **原创守门者/Boss**：两个阶段有不同决策压力、可读前摇和反制窗口；近战、远程、控制至少各有通关证据。原创贴图及真实动画需独立视觉复核，不把代理自评包装为外聘画师认证。
5. **营地 NPC 任务与对白演出**：先一条能影响行动、造物或路线的完整短任务链；对白可跳过、可回看、存档恢复不重复发奖，不靠长文本撑时长。
6. **音效完整化与最终平衡**：统一色板/像素尺度/人物握持，按武器材质和敌人反应区分音效，压住混音峰值；以 10–15 分钟真实有效体验为目标，再考虑扩量。

最终需要首次接触的玩家实际试玩：能说明为什么选该物品/强化、看懂敌人预警，并愿意换构筑再试。
这是一项待验证目标，不保证每个人都觉得好玩；记录实际战斗、阅读、暂停、造图等待分别用时。
