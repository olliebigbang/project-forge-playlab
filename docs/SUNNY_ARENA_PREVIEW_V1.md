# SunnyLand 宽地面独立小样

日期：2026-08-31。基线 `39205a92`，原工作区未提交开发全部保留。

## 范围

用户要先看宽阔战斗地面是否能与 SunnyLand 融合。这一版是可走动的
**环境、比例和预警配色样板**，不是第二套战斗系统或主游戏换皮。
默认教堂入口、机制轴、敌人招式、玩家武器、武器库和存档均未修改。

新增：参考 SunnyLand 生成的宽空场背景；原包狐狸、青蛙和灌木；
前后左右走动、脚底前后排序、可开关的预警配色示意、纯背景查看。
沙土地面是新画的表面，不是放大平台侧壁；全背景也是 AI 参考重绘，
不能将它描述成“原包地图直接拼装”或“逐像素人工绘制”。

狐狸只是大小与走位标尺，不是最终主角。本环境样板制作时尚未取得
Dead Revolver 完整素材，没有接入，也没有修复/认证原玩家握持。后续用户
提供原包后，已另建 [Sunny 人形持械小样](SUNNY_PLAYER_PREVIEW_V1.md)，不覆盖本入口。
本环境样板不接实际打击、伤害或三章
关卡；红圈明确是配色示意，不冒充由敌人机制运行时发出的攻击。

## 打开

双击仓库根目录 [Preview-Sunny.cmd](../Preview-Sunny.cmd)。
也可从任何 PowerShell 目录执行：

```powershell
& '<USERPROFILE>\Documents\ChatGPT\playlab\combat-mechanism-integration-v1\scripts\run_sunny_arena_preview_v1.ps1'
```

默认打开优化版 V3。WASD/方向键前后左右走；B 切换 V2/V3；
J/空格切换预警示意（默认关闭）；Tab 隐藏文字；
H 隐藏角色与灌木看纯环境；R 复位；F8 保存引擎截图；Esc 退出。
世界320x180、中文界面640x360，默认1280x720整数放大；缩放窗口保持比例。
不读取 `.env`，不在线生成，不读写个人武器或游戏存档。

## V3 优化与验证

后续优化只改本独立样板，没有改动教堂关卡或持械系统：

- 通过一次内置图像编辑生成 V3：浓橙色地面收成浅土黄，减少碎小横纹，
  整理后沿和前景草边。旧 V1/V2 原图保留，未覆盖。
- 可走地面由 `Rect2(58,224,524,100)` 改为 `Rect2(58,210,524,114)`，
  宽度不变，前后可走距离增加14%；上边界根据实际出图设置。
- B 切换背景、灌木位置与对应地面边界，不重置动画或朝向；处于两版
  共用地面内时位置不变。若站在 V3 新增的远侧区域，切回 V2 会将脚点
  限制回旧边界，这不是完全相同布局的像素差分。
- 默认关闭红圈；需要时按 J 查看。UI 仍独立于320x180世界像素网格。

第11/12帧的角色坐标、朝向、动画时刻相同，便于比较环境而不是比较姿态。
这是自动输入的真实渲染，不是桌面手动试玩，没有运行或重报主游戏353项回归。

V3 仍未达到严格三色地面或无渐变，树冠体积感也仍比原包强；提示词目标

## 独立视觉复核与修订

审核者：独立代理 `sunny_sample_visual_review`，不是外聘画师。

### 最新 V3

审核者亲自查看 V3 回放的第1/2/3/6/7/9/10/11/12共9张真实 Godot 图，
其中11/12为同姿态前后对照。结论：**通过环境样板复审，可以交付查看**。
地面比 V2 少橙、少碎线，角色更突出；像素尺度协调，没有第一版的明显
粗细断层。抽样远边脚底在草线前的土面，近边没有踩穿前景或明显漂浮；
前后遮挡顺序正确，界面未见裁切。

仍有三点审美限制：更像明快的黄土地训练场，场景性格普通、中央偏空；
地面仍较饱和，不等于柔淡自然草地；树冠和房屋明暗变化多于原角色，
不能称为原作者笔法完全一致。通过仅限上述样本，不覆盖正式关卡、
实战可读性、人物持械、完整动画或所有边界坐标。

### V1/V2 历史复核

首轮亲自查看7张Godot图和原SunnyLand参考：宽地面与明快方向成立，
但背景像素比角色细密、中央灌木完全遮人、警示更像选中圈。

据此通过第二次内置图像编辑简化云层/树林/草边，统一世界渲染到320x180，
不降低中文UI分辨率；灌木移到走位范围后侧边缘，警示改红填色/暗描边。
v2重新取得9张真实渲染，审核者亲自复审其中7张，结论为
**通过：可展示的小型环境样板**。像素密度断层显著改善，中央遮人消除，
红圈对比更明确，界面完整、前后排序正确。

审核又指出青蛙轻微悬浮。实际测得青蛙4帧最低不透明行为26，而32px画布
下有5行透明留白；狐狸待机4帧最低行为31。按可见脚底而非画布底对齐，
再次取得9张截图及通过检查。审核者复看最后普通/纯画面两帧，确认
悬浮感消除、狐狸落地正常、没有新阻断，维持环境样板通过。

对v2纯背景640x360实际截图检查全部2x2像素块，非一致块计数为0，证明
320原生世界网格确实生效；这不是对色数、美感或原包一致性的自动认证。

仍有差异：新树冠体积感、地面渐变比原包强。这是同风格再创作，不能
宣称原作者逐像素一致或无缝融合完成。审核没有覆盖真实战斗、最终主角、
武器握持、全动画或正式上线。代理审核不等同外聘画师认证。

开发中首次v2启动在导入完成前加载新纹理而失败；没有作为成功证据。
独立启动器已显式等待隐藏导入进程完成，再打开样板。随后最终回放正常，
无脚本/渲染错误。没有修改主游戏启动器。
