| 已有状态/结构 | 实际人物动作 | 边界 |

| 移动、闪避、受击、死亡 | 原包对应全身帧 | Shift/K 仍是已有闪避，不新增平台攀爬规则 |

训练场载入的107组图不等于主游戏增加107种技能。弓、徒手、抓取等仍以原动作训练场的条件/检查用途为准，本次没有凭一张动画凭空增加对应战斗系统。原包没有持竿行走：移动时采用实际走路身体/腿，不能把钓鱼站姿平移冒充行走。

普通源画布96×84、钓鱼143×104，使用固定脚点，身体源像素按3倍绘制。AI武器独立按真实轮廓与两手跨度适配，不把所有物品强制归成32×32。使用nearest，身体文件不重画。

## 持械与命中约束

1. `scripts/authored_player/source_rig.gd`读取原Aseprite帧时长和分离图层。原Weapon层只作握姿测量，正式战斗不画原占位枪、绿剑或原武器FX。
2. `scripts/authored_player/arena.gd`适配真正的AI武器：手臂由原手臂像素做两段关节变换，不画小棍代手；主副手跟随真实GripPrimary/GripSecondary，柔性绑定使用同一变形器。
3. 人物源手臂有遮挡切片，部分颈胸像素位于手臂层。移动双臂时保留Head+Torso核心区域里的原颈胸像素，头仍在原帧坐标，不补造新颈部。只在运行时忽略1–4px的离散动作碎屑，源PNG不改。
4. 原包跑斩的收手时机与机制有效段不完全相同。有效段将真实持物手过渡到机制前向接触位，保留身体、腿、起势与收势；否则会发生角色向前攻击但物品还在身后。
5. 枪身大小、枪管高度和手位共同适配。近身时实际手臂/整枪后收，子弹不向后瞬移。蹲射从下移后的真枪口发出；原后坐力/散布仍可能使单发偏离水平。
6. 可见近战接触像素和伤害查询共用一帧；实际敌人使用已有身体受击轮廓，不再只检查旧人物高度下的脚底圆。伤害数值、敌人强度没有降低。
7. 编译动作显式携带`trajectory_plane`。`ground_sweep/ground_orbit`按侧视投影生成角度、纵向缩短和前后绘制层：朝向镜头时真实物品变短，绕到人物后方时武器与持物前臂先画，回到前方时后画。可见像素、握点和接触判定读取同一投影结果。

结构动作语法给每个已编译动作附加`presentation_family`和`trajectory_plane`，身体帧和机制接触仍在运行时合成。长柄尖端三段使用`pole_jab/pole_rake/pole_pin`，分别对应直线前刺、地面横扫和屏幕平面下扎；带重柔性三段使用`weighted_cast_low/weighted_lash_cross/weighted_retract`，走地面环身或横扫。柔性视觉绑定即使把同一物体自动拆成`deform_body`和`tether`，运行时也先生成一条从真实握点到真实末端的定长连续弧，再按原像素角色切回两段；可见锁头位置就是接触位置。通用物品显示名不参与选择；枪管结构明确排除在长柄尖端语法之外。

## 操作和交接

- 主远征原操作不变；静止时 C 可蹲射，低目标自动蹲射默认开启。
- Sunny：WASD移动，J/空格攻击/蓄力，K/Shift翻滚，C蹲射，G开关自动蹲射，1–5换既有武器，R重置练习。
- 本轮未读取`.env`、调用AI、修改个人存档/武器库、提交或推送；离线验证使用隔离数据。
- 尚未证明任意新AI物品的全部动作、美术统一完成或真人重复游玩的体验；白人偶仍是动作适配阶段，不是最终人物皮肤。
