# 晴日远行：横向推进主流程

当前核对：2026-09-04。主入口 `scenes/sunny_expedition.tscn`，双击 `Play-Sunny.cmd`。
离线：`./scripts/run_sunny_expedition.ps1 -Offline`。旧 `Play-Church.cmd` 保留，
但晴日流程不跳回教堂。开发文件仍在当前 worktree，未提交或推送。

## 已接通的范围

文字造物 → AI身份/结构声明 → 本地机制校验/编译 → 像素图校验 → 完整武器库
→ 选择第一章故事远征或8怪试铸场 → 真实向右推进 → 路标构筑/段间路线 → 守门战 → 结算。

长关卡宽4480像素，超过三个1280像素屏幕。玩家、敌人、弹体、危险区和命中
判定都保留真实世界坐标；镜头跟随玩家向右移动，不是固定场地上的背景假滚动。
试铸场每个路标8秒有效守护进度；四段敌人数依次为2、2、2、1，最后另有
1只守门者，整局严格共8只。离开不倒退，敌人占据中心会暂停。进度满后还必须
清完当前路段剩余敌人。前三段随后暂停并提供一次机制三选一，选完前方路障才
开放；第四段清除守门者。远处路段不会在
玩家两屏之外提前刷怪。暂停、失败重试、完成历史继续使用既有远征状态机。
Sunny采用单独的`sunny-expedition-v1`目录，不覆盖旧教堂进度。

默认正式入口为“第一章·被忘掉的送货单”。三段场景为蒲公英驿道、回声溪桥、
荆棘后的空白，敌人总预算依次为12、14、16只。段间可选溪桥（降低追击压力）、
菌伞林（先给3锻材并改变出怪序列）或旧风坡（提高风险、先给稳定核心）。已选机制
强化、未花锻材和核心跨段保留并进入中断存档；试铸场仍保持短流程，方便逐一验武器。

当前背景为了连续和干净，使用同一森林主题图的原图/水平镜像交替衔接；不再将
村口、森林、溪谷三张不同构图硬拼出竖缝。真正的多区域宽背景是后续美术工作，
本轮不拿硬切假装完成。

## 局内机制构筑

前三个路标各提供三项：强化优势、改变打法、高收益代价。枪械候选读取当前弹道、
供弹、伤害、穿透、散布、装填、后坐力等已编译参数；普通物品读取接触面、重量
分布、软体/牵引结构和功能输出。没有枪名或物品名配方。选择后直接修改当前局的
运行参数，路障才会开放；第四段使用累计三项构筑打守门者。

当前强化只在本次远征有效，重开会按种子重新给出候选；武器库中的原武器不会被永久
改写。正式故事远征会跨三段累积至多九项选择，战斗顶部持续显示当前路线和构筑。
封顶局外见闻和段间三路线已接入；图形化随机节点、商店或独立事件房尚未接入。

## 通用机制没有退化为物品菜单

- 枪械和普通物品继续走各自声明校验与现有机制轴编译。没有长叉、壶或链的名称招式分支。
- 真实图片、Primary/Secondary握点、软体变形、有效接触共用根姿态。
- 敌人仍使用已校验攻击蓝图与状态机；名称与Sunny蛙/狐狸外观只是展示索引。
- Sunny造物通过`sunny_v1 / sunny-pixel-v1.0`风格合同传入普通物品、枪械两条桥接，
  限色、透明边缘、轮廓及结构要求沿用校验；风格进入请求与缓存指纹。
- 旧合格武器调色生成独立展示副本，Alpha、握点、结构绑定不变；不会偷偷生成新武器。
- 新物品需要真实语义与图像服务，失败停止，不替换样本；本轮只离线验证新风格合同，
  未执行新的端到端FAL物品生成，因此不承诺任意新输入成功或新图必然美术合格。

## 动作与视觉处理

使用Dead Revolver原包全身帧：前刺SwordCombo03、横扫StandingSlash、
下砸SwordSlash01、广弧SwordCombo01；原帧的起手/有效/收招区间由机制时间驱动。
移动或蓄力不再把前刺替换成反向跑斩。第二段反向横扫保留完整角幅；次接触面
不再无条件推断成背端，只有明确枪托等结构证据才能使用rear_contact。

原导出的某些RightArm是速度拖影，不是完整解剖手臂。以相邻清晰原臂为供体，
对齐当前帧真实肩部；深V弯肘取真实远端转折。Torso远离躯干/头的拖影片不作为
身体或锚点依据，与Head邻接的真实颈块必须保留，并恢复源臂层中的颈胸遮挡像素。
短柄物品避开真实头区，手臂长度和双握点约束不放开，画面与接触一起移动。
原PNG不覆盖；这不是每帧逐像素原样播放，也不是新人物皮肤完成。

背景为已认可村口加内置imagegen生成的林地、溪谷，源图与提示词保留在
`assets/sunny_expedition_v1/`。敌人当前使用同作者SunnyLand弹簧菇、毒雾菇、
幽灵和食人花精灵、状态动作偏移与机制预警；重型守门者为食人花的放大精英，
仍不是独立原创Boss美术。
